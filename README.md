# Description

The goal of this project is to recreate the printf function from scratch.

# Instructions

Make sure to include the header files at the top of your C file:

#include "ft_printf.h"


You can then compile your program by typing:

cc main.c libftprintf.a


Here, main.c is the C file you created.

The project includes a Makefile to compile libftprintf. Using the command make creates libftprintf.a.

make - Compiles the library and creates libftprintf.a.
make clean - Removes object files.
make fclean - Removes object files and the library.
make re - Recompiles everything.
